================================================================================

📋 WHAT YOU NEED TO DO:

1. GET YOUR API KEY
   ├─ Visit: https://makersuite.google.com/app/apikey
   ├─ Sign in with your Google account
   ├─ Click "Create API Key"
   └─ Copy the generated key (looks like: AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX)

2. SET THE API KEY
   
   METHOD 1 - Use the Setup Script (EASIEST):
   ├─ Double-click: set_api_key.bat
   ├─ Paste your API key when prompted
   └─ Press Enter

   METHOD 2 - Edit .env File Manually:
   ├─ Open the file: .env
   ├─ Find the line: GOOGLE_API_KEY=your_api_key_here
   ├─ Replace with: GOOGLE_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   └─ Save the file

3. RESTART BACKEND
   ├─ Stop the backend server (Ctrl+C if running)
   ├─ Start it again: python backend/app.py
   └─ Look for: ✓ Gemini API key loaded successfully
